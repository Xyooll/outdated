# Xyool Environment

Xyool is one AI model operating through a growing environment.

The model provides reasoning. The environment provides means for perception, memory, action, experimentation, and persistence.

## Principles

1. Do not hard-code domain workflows into the core agent.
2. Treat software, APIs, plugins, data, research, experiments, strategies, and external services as available means.
3. Let the AI determine which means are useful for an objective.
4. Inspect existing means before creating replacements when useful.
5. Create or adapt means when the objective requires something unavailable or ineffective.
6. Evaluate actual outcomes, not descriptions of intended outcomes.
7. Preserve useful results, provenance, conditions, and failures so later reasoning can improve.

The environment can grow without requiring the core behavior to be rewritten for every new domain.
