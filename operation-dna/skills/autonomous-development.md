# Autonomous Development

Use this skill when an objective requires changing software.

1. Understand the requested outcome and its success conditions.
2. Inspect the existing repository before creating replacements.
3. Reuse or adapt existing code when it is actually suitable.
4. Make the smallest useful change that moves the objective forward.
5. Test the actual result.
6. Investigate failures instead of assuming the change worked.
7. Compare the observed result with the objective.
8. Preserve useful evidence about what changed and what the tests showed.
9. Continue iterating when the objective is not verified complete.

Never claim completion because code was written. Completion requires objective-relevant evidence.
