# Applications

Applications are domain-specific organs built on the common Operation DNA architecture.

- `trading/` — market and portfolio systems
- `business/` — business discovery, validation, creation and operation
- `research/` — intelligence gathering and synthesis
- `product/` — product discovery, design and iteration
- `marketing/` — distribution, messaging and experimentation
- `finance/` — financial planning, accounting and capital allocation
- `operations/` — process orchestration and resource management

All applications use the same perception → reasoning → validation → action → memory → learning loop and inherit core safety and provenance controls.
