# FLOW — Research

FLOW ID: `CORE-RESEARCH`  
STATUS: **ACTIVE**

## GOAL
Reach a sufficiently supported answer using the minimum justified external work.

## PROCESS
```text
DEFINE QUESTION
→ IDENTIFY DOMAIN / SCOPE IF APPLICABLE
→ CHECK DOMAIN LIBRARY + EXISTING STATE/EVIDENCE
→ ASSESS STORED SCOPE / FRESHNESS / VALIDATION
→ IDENTIFY MATERIAL GAPS
→ RETRIEVE AUTHORITATIVE EXTERNAL EVIDENCE ONLY FOR THOSE GAPS
→ CROSS-CHECK WHERE CONSEQUENCE WARRANTS
→ SEPARATE FACT / INFERENCE / UNKNOWN
→ IF RESULT IS MATERIALLY REUSABLE: WRITE BACK TO DOMAIN LIBRARY WITH PROVENANCE
→ STOP WHEN GOALPOST IS SUFFICIENTLY SUPPORTED
```

## ADAPTATION
Research depth expands only when unresolved uncertainty could materially change the answer.

## OUTPUT STATE
Evidence-backed result, provenance, contradictions, confidence, blockers.

## SOFTWARE / HARD-LIMIT BOUNDARY
Software may assist retrieval/parsing at scale; reasoning remains Floware.


## DOMAIN-LIBRARY RULE

For domain work, internal reuse is the first research step, not the last.

Correct order:

~~~text
LIBRARY FIRST
→ refresh only stale/dynamic/conflicted knowledge
→ research only real gaps
→ write back reusable distilled knowledge
~~~

Do not repeat stable external research merely to recreate a rule/method already captured with sufficient provenance and scope.

The library never suppresses external refresh when the answer depends on current state, contested evidence, or a source version that may have changed.
