# FLOW — Authorized Execution

FLOW ID: `CORE-EXECUTION`  
STATUS: **ACTIVE**

## GOAL
Accomplish an authorized operational objective using the minimum necessary actions.

## PROCESS
Understand outcome → identify consequence/authorization → select smallest action path → act → verify consequential result → report unresolved uncertainty.

## BOUNDARIES
High-consequence, destructive, financial, privacy, security, or difficult-to-reverse actions retain their applicable explicit authorization requirements.

Floware may decide how to pursue an authorized objective.

Floware may not waive hard permission boundaries.

## SOFTWARE / HARD-LIMIT BOUNDARY
External transactions, permissions, security enforcement, and deterministic safety constraints remain software/tool responsibilities where applicable.
