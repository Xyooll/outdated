# User Concepts / Thought Ledger

Status: **ACTIVE / HUMAN-ORIGINATED MEMORY**

Purpose:

> **Preserve material thoughts, concepts, rationale, philosophies, design intuitions, and naming choices expressed by the user so they can be revisited later and understood by another person without reconstructing them from scattered chats.**

## Capture rule

Capture a concept when it is materially one of:
- a new conceptual distinction;
- a philosophy or principle;
- a rationale behind an architectural choice;
- a naming/terminology decision;
- a goal or definition of "finished";
- an intuition that may later become research;
- a correction to how Xyool should think;
- a belief about the future that materially shapes the system;
- an explanation of why the user wants something built a certain way.

Do **not** log every casual sentence.

The ledger should remain meaningful.

## Entry structure

Each material entry should preserve:

```text
DATE / CONTEXT

USER WORDING
A short exact quote or faithful excerpt where useful.

CONCEPT
A concise statement of the idea.

RATIONALE
Why the user appears to hold the idea, based only on what they actually expressed.

SYSTEM INTERPRETATION
How Xyool understands the idea.

SYSTEM EFFECT
What changed in architecture, terminology, goals, or operation.

OPEN QUESTIONS
What remains uncertain.

RELATED CONCEPTS
Links to earlier/later entries.

STATUS
ACTIVE / EVOLVING / REVISED / SUPERSEDED / QUESTION
```

## Authorship discipline

Never present assistant inference as the user's belief.

Use labels:

- **USER-STATED** — directly supported by the user's words.
- **ASSISTANT INTERPRETATION** — a derived reading.
- **SYSTEM CONSEQUENCE** — how Xyool used the idea.

## Legacy readability

Entries should be understandable by someone who has never used Xyool.

Avoid unexplained internal acronyms where a plain-language explanation can be added.

A loved one or future collaborator should be able to read the ledger and understand the user's reasoning, values, and intellectual development without needing the original chat history.
