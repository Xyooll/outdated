# User Concept — Characters Are Re-Rootable Stories

Date: **2026-09-23**  
Status: **ACTIVE / CORE STOCK ARCHITECTURE**

## USER-STATED CONCEPT

Even when an entity is a subsidiary, it is still its own character.

If the user later wants to research that subsidiary as the main character, Xyool should already have enough of its story saved to start from the known state instead of rebuilding it.

## CANONICAL INTERPRETATION

> **Subsidiary is a relationship role, not the character's identity.**

Every material company/entity gets reusable Character Memory.

A character may appear as:
- subsidiary in one story;
- customer in another;
- partner in another;
- main character when re-rooted.

When re-rooted:
- it becomes Degree 0;
- it receives a full four-degree research horizon;
- known evidence and relationships are reused;
- degrees are recalculated relative to the new root;
- only missing/stale/newly in-scope branches are researched.
