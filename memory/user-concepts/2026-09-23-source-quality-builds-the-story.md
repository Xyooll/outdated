## CONCEPT

Research/sourcing is not separate from narrative construction.

The stock story is built from evidence, so source quality constrains story quality.

This applies recursively to the parent and every material character/subsidiary.

## ASSISTANT INTERPRETATION

Canonical chain:

```text
BEST AVAILABLE SOURCES
→ CLAIMS
→ CHARACTER STATES
→ CONNECTIONS
→ STORY
→ THESIS
```

For material relationships, use both sides of the relationship where possible.

Source authority is claim-specific. An issuer filing can contain both hard facts and management claims; those should not be treated as equivalent.
