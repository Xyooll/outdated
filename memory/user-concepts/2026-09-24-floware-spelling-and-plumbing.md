# User Concept — Floware spelling and plumbing vocabulary

Date: 2026-09-24
Status: **ACTIVE / CANONICAL TERMINOLOGY**

## USER-STATED

The canonical word is **Floware**.

When spoken, speech-to-text may render it as "Flowware," but the intended architecture name remains **Floware**.

Because Floware has Flows and Pipes, the collective connection structure can naturally be called **Plumbing**.

## SYSTEM CONSEQUENCE

Canonical terminology:

~~~text
FLOWARE
= the architecture

FLOW
= does the work

PIPE
= connects Flows

PIPELINE
= connected Flows + Pipes toward an objective

PLUMBING
= the collective Pipe/connectivity structure
~~~

Speech-to-text normalization rule:

~~~text
spoken "Flowware"
when referring to the Xyool architecture
→ interpret / write as "Floware"
~~~

unless context clearly means ordinary software/flowware terminology.

This is a naming/ontology clarification, not a change in authority.
