## Core law

More symbols create more opportunities to fit outcomes.

Freeze before confirmatory outcome review:
- degree corpus;
- star catalogue and inclusion threshold;
- contact geometry and orbs;
- asteroid set;
- aspect set;
- house system;
- timing techniques;
- outcome taxonomy;
- forecast windows;
- confidence/probability mapping.

Prohibited rescue behavior:
- add a star after a miss;
- add an asteroid because its name matches an event;
- widen an orb after the window;
- switch degree corpus post hoc;
- add timing methods after seeing the outcome;
- relabel the outcome category to preserve a hit.

Track the denominator: objects searched, rule families, calendar coverage, outcome categories, forecasts/windows.

Search-space expansion without incremental out-of-sample value should cause simplification.
