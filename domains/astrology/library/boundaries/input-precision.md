## Learned failure pattern

A reported-time correction can invalidate:
- natal house state;
- profection state;
- Story Reader state;
- future Writer branches.

Correct response:

~~~text
CORRECT INPUT
→ SUPERSEDE OLD CALCULATION STATE
→ INVALIDATE DEPENDENT OUTPUTS
→ RECALCULATE
→ REBUILD ONLY AFFECTED STORY STATE
~~~
