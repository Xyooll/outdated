# ASTRO-LIB-SYSTEM-SEPARATION

TYPE: DOMAIN BOUNDARY
STATUS: **DOMAIN-ESTABLISHED**
SCOPE: all Astrology work
LAST REVIEWED: 2026-09-25

## Summary

Astrology systems/traditions must produce independently labeled native outputs before synthesis.

Do not silently merge:
- modern Western;
- traditional/Hellenistic Western;
- Western sidereal;
- Jyotish;
- fixed-star/stellar;
- Maya traditional/living calendrical systems;
- Dreamspell;
- heliocentric/experimental systems.

## Boundary

Shared astronomical inputs or agreeing stories do not make systems independent confirmations.

Cross-system synthesis requires explicit dependency/correspondence handling.

## Validation status

Architecture/domain-identity rule only.

It does not establish predictive efficacy for any participating system.
