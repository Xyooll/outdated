## Freshness classes

HISTORICAL_PRIMARY_RULE — stable; refresh for edition/translation/source conflict.

XYOOL_INTERPRETIVE_RULE — immutable/versioned; change by explicit new rule version.

EPHEMERIS_ENGINE — release-sensitive.

SMALL_BODY_ORBIT_SOLUTION — dynamic; refresh when precision is material.

FIXED_STAR_CATALOG — catalog/data-release versioned.

EMPIRICAL_VALIDATION — evidence accumulating.

RELEASE_SCHEDULE — time-sensitive; never treat as permanent.

## Gaia example

The Deep Research identified Gaia DR3 as the current stellar audit source and a planned later Gaia release as a future migration event. Treat any future release as a catalog delta, not a reason to rewrite Star Astrology history.

## Library rule

Reuse stable knowledge internally. Refresh only dynamic, stale, conflicted, or materially higher-consequence state.
